# 基因表达实验室｜从基因到蛋白质

面向高中生的中文互动课。从真核细胞剖面进入，按七个场景观察转录、RNA 加工与出核、翻译和多肽折叠。

## 离线启动

双击 `dist/index.html`，用 Chrome 或 Edge 打开。保留 `dist` 中的全部文件及目录结构。页面采用本地 HTML、CSS、JavaScript 和内联 SVG，打开后即可离线运行。

课堂投屏可用页面右上角的「全屏」和「大字」。从左侧进入任意场景，在底部播放、拖动或单步观察。遇到橙色时间轴刻度，完成右侧题目或点击对应结构后，动画继续。重播会重新开启本步任务。

## 源文件

- `dist/course.js` 包含教学文案、关键帧、反馈和示例序列。
- `dist/molecules.js` 包含 SVG 分子图和各场景的运动。
- `dist/player.js` 管理播放、答题、缩放及投屏控件。
- `dist/index.html`、`dist/style.css` 和 `dist/mark.svg` 定义页面结构与视觉样式。

## 教学说明

转录与翻译共用一段编码示例。RNA 加工使用独立的外显子与内含子结构示意，折叠场景换用更长的多肽模型。分子大小、时间和距离均为教学示意。
